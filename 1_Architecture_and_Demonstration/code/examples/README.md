# Saved examples

Offer files contain the text, assigned role and any previous-offer context. Interpretation files contain saved LLM responses. The demo calculates scores from these saved interpretations without making API calls.

| Filename | Description |
| --- | --- |
| [appendix_a_offer.json](appendix_a_offer.json) | Informal offer used in Appendix A, including shorthand and spelling mistakes. |
| [appendix_a_interpretation.json](appendix_a_interpretation.json) | Saved interpretation producing Candidate +7.80 and Recruiter −5.30. |
| [job_offer.json](job_offer.json) | A basic Candidate job proposal. |
| [job_interpretation.json](job_interpretation.json) | Its saved interpretation. |
| [counteroffer_offer.json](counteroffer_offer.json) | A Recruiter counteroffer. |
| [counteroffer_interpretation.json](counteroffer_interpretation.json) | Its saved interpretation. |
