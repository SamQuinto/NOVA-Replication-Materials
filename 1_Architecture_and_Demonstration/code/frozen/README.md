# Exercise files used for validation

These files preserve the exercise definitions used to produce the reported results. The job version contains 215 issues. The current 216-issue scoring table is provided in `2_Exercise_Materials/scoring_tables/`.

| Filename | Description |
| --- | --- |
| [A1_Exercise.json](A1_Exercise.json) | Exercise information and conventions supplied to A1. |
| [A1_Scoring_Definitions.json](A1_Scoring_Definitions.json) | All active job issues and options supplied to A1, without numerical scoring weights. |
| [A2_Reading_Rules.json](A2_Reading_Rules.json) | Job-exercise reading instructions supplied to A2, discussed in Appendix B and Table B1. |
| [Role_Materials.json](Role_Materials.json) | Candidate and Recruiter role materials used by the scorer. |
| [SOURCE_FIRST_FORMAT.json](SOURCE_FIRST_FORMAT.json) | Required JSON interpretation format for the main exercise. |
| [Scoring_Table.json](Scoring_Table.json) | The 215-issue scoring table used by the Python scripts for the main validation. |
| [tutorial/](tutorial/) | Corresponding files for the nine-issue venue-hire tutorial. |
