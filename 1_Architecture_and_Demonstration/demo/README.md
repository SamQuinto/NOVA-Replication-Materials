# Downloadable web app

Follow the setup and API-key instructions in the parent README, then run `python demo/Start_Demo.py` from the architecture folder. Saved examples work without a key.

| Filename | Description |
| --- | --- |
| [Start_Demo.py](Start_Demo.py) | Starts the web app and handles scoring requests on your computer. |
| [index.html](index.html) | The browser interface, including the role-materials panel, offer box and score display. |
| [role_materials.json](role_materials.json) | Formatted main and tutorial role materials displayed by the app. |
