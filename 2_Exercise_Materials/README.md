# Negotiation exercise materials

Start with the [negotiation exercise role materials](Negotiation_Exercise_Role_Materials.pdf). This document brings together the main exercise and tutorial, with a short introduction to each.

The **main exercise** is a two-party job negotiation: one person plays the Candidate and the other plays the Recruiter. With NOVA, negotiators write offers in their own words.

The **tutorial** is a short venue-hire negotiation. Participants in our pilot studies completed it before the main task to become familiar with NOVA and its scoring calculator.

Both roles are included for researchers to read. When running a study, give each negotiator only their own role information.

Both workbooks have just two sheets: **Scoring table** and **Scoring logic**. Continuous entries are labelled as reference values, not a fixed menu of allowed offers.

The current job table adds **Workplace Coffee** after the October 27 pilot. Following the November 3, 2026 update, free coffee is worth +1 to each party; no free coffee is worth 0 to both. The [current JSON](scoring_tables/flexible-216.json) contains the same 216 issues as the main scoring workbook. The original 215-issue JSON and frozen architecture inputs are retained only to reproduce the reported validation results.

The Survey Questionnaire includes the questions, response choices and survey dates. The machine-readable versions are combined in [questionnaire_configurations.json](../3_Validation_and_Development/supporting_files/data/questionnaire_configurations.json). Participant responses and analysis are in [Validation and Development](../3_Validation_and_Development/).
