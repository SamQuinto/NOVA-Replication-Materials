# Calculated results

`Analysis.ipynb` and `supporting_files/analysis.py` generate these files from the supplied records.

| Filename | Description |
| --- | --- |
| [Accuracy_and_Costs.csv](Accuracy_and_Costs.csv) | Accuracy, Wilson confidence intervals, Type A and Type B counts, API costs and mean scoring time for Tables D1 and D2. |
| [Behavioral_Summary.csv](Behavioral_Summary.csv) | Negotiation activity and creative issue development, including the means, SDs and confidence intervals reported in Table D3. |
| [Agreement_Rates.csv](Agreement_Rates.csv) | Agreement rates and confidence intervals for eligible and completed NOVA negotiations. The completed sample is used in Table D3. |
| [Issue_Frequency.csv](Issue_Frequency.csv) | Frequency of each of the 19 additional issues, divided between opening offers and later introduction. Used for Figure 2. |
| [Survey_Summary.csv](Survey_Summary.csv) | Descriptive summaries of the NOVA post-negotiation measures, shown in the notebook. |
